# R20.2 — Reproducible header; no timestamps

**Milestone:** M11 — Emission polish
**Status:** done
**Spec:** §11, R20.2
**Depends on:** R20 (the file mechanism)
**Unblocks:** byte-for-byte reproducible builds; stable golden tests

## Goal

Each file carries library version, generator class, and parameters. **No
timestamps** — output is byte-for-byte reproducible for identical input, which
is what makes golden tests and reproducible builds work.

## Scope for M11

- [x] Header: library version (from build), generator class name, top-module
      parameters (encoded per R16).
- [x] No timestamp, no random id, no hostname, no username.
- [x] The first emitter had a minimal header; this milestone makes it the full
      contract.

## Exit criteria

- [x] Two emission runs over identical input produce identical bytes
      (including header).
- [x] Header includes version + generator class + parameters.
- [x] A grep for `Instant.now`/`System.currentTimeMillis`/`UUID` in the emitter
      finds none feeding output.

## Outcome

Done on 2026-08-12. The core build now generates `scalahdl.BuildInfo` from
sbt's `version` setting, and `Emission` uses that version by default rather
than requiring callers to duplicate build metadata. Elaboration captures the
top generator's fully-qualified runtime class name and its ordered,
name-contributing R16 parameter segments in immutable `GenerationInfo`; every
emitted file receives the same canonical three-line header. An empty R16
parameter sequence is rendered as `none`.

`EmissionHeaderSuite` verifies the build-derived version, captured generator
class, ordered Int/Boolean R16 encodings, canonical false-Boolean omission, and
byte-for-byte equality across two runs. Existing Verilog goldens were updated
to the full header contract. The full build passes 146 tests (131 core, 15
examples), including Verilator checks, and the required emitter grep finds no
`Instant.now`, `System.currentTimeMillis`, or `UUID` use.
