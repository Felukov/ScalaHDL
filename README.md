# ScalaHDL

A Scala 3 HDL targeting Verilog-2001, for educational and research use.

The design is governed by three non-negotiable properties — **correspondence**,
**locality**, and **explicitness** — from which every requirement in
[`hdl-spec.md`](hdl-spec.md) follows. The spec is the contract; this README is
the shortest path to a first emitted file.

## What the output looks like

A counter is ordinary Scala:

```scala
class Counter extends Module:
  val clk   = In(Clock())
  val rst   = In(Reset(ActiveHigh))
  val en    = In(Bool())
  val count = Out(UInt(8))
  given defaultDomain: ClockDomain = ClockDomain(clk, rst, ResetKind.Sync, ActiveHigh)
  val cnt = Reg(UInt(8), init = 0.U(8))
  when(en) { cnt := cnt + 1.U(8) }
  count := cnt
```

and it emits Verilog-2001 a reader maps back to it line by line:

```verilog
// Generated by ScalaHDL 0.1.1
// Generator: scalahdl.examples.Counter
// Parameters: none
module Counter(
  input clk,
  input rst,
  input en,
  output [7:0] count
);
  reg [7:0] cnt;
  assign count = cnt;
  always @(posedge clk) begin
    if (rst) begin
      cnt <= 8'd0;
    end else if (en) begin
      cnt <= (cnt + 8'd1);
    end
  end
endmodule
```

## Getting started

Use ScalaHDL as a library from a separate sbt project. The
[quick-start guide](howto.md) covers adding the library as a source dependency,
project setup, a complete counter, Verilog generation, and the temporary
in-repository fallback.

## Layout

```
hdl-spec.md        the requirements contract (read this)
build.sbt          sbt build, two subprojects: core + examples
core/              the library
  src/main/scala/scalahdl/
    Module.scala   the ordered validation phases
    core/          the intermediate representation
    dsl/           surface syntax, name capture, `simOnly`, `Interface`,
                   crossing primitives, memories, `Handshake`
    elab/          elaboration into the intermediate representation,
                   including black-box declarations
    clock/         clock domains, reset, clocking traits
    validate/      validation phases
    diag/          structured diagnostics
    emit/          backends (Verilog-2001 primary) and file organisation
    lib/           components a design imports — Skid, the synchronous FIFO
  src/test/scala/scalahdl/
    ...            one directory per concern
  src/test/verilog/ SystemVerilog testbenches over the emitted Verilog
examples/          designs built against the library
  src/main/scala/scalahdl/examples/
    Counter.scala  the minimal end-to-end slice
    AsyncFifo.scala the validation exercise
```

## Building

```
sbt compile
sbt core/test
./emit.sh scalahdl.examples.Counter   # emit a module from the in-repo examples
./tools/lib-sim.sh                    # the library's testbenches through Verilator
```

`./emit.sh <fully-qualified-class> [output-dir]` elaborates a no-argument top
module from the `examples` subproject and writes one Verilog file per module,
the reports, and `manifest.f`, to `generated/verilog` by default. A design that
does not validate prints a diagnostic — the offending source line with a
caret — and exits non-zero; it prints no Java stack trace.

`./tools/lib-sim.sh` requires Verilator on `PATH`; without it the script exits
2. The Verilator-dependent `sbt test` suites skip when Verilator is not on
`PATH`, so `sbt test` is green without it; installing Verilator adds that
lint/simulation coverage and enables `./tools/lib-sim.sh`.

Scala 3.3.8 (the 3.3 LTS line) on **JDK 17 or newer**. No compiler plugin: name
capture uses `inline def` and `Symbol.spliceOwner`, deliberately. `sbt test` runs
the whole suite; `./tools/lib-sim.sh` adds the Verilator runs.

## Status

ScalaHDL is mostly complete for its current specification. Some requirements are
not yet met; the [roadmap](roadmap/README.md) lists the milestones still open.
The library is version `0.1.1`, so the API may change. It is intended for
educational and research use, not as a stable foundation.
